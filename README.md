# Calculator

A lightweight, responsive calculator application built with pure HTML, CSS, and JavaScript. No frameworks or external dependencies required!

## Features

✨ **Core Features:**
- Basic arithmetic operations (addition, subtraction, multiplication, division)
- Clear/Reset functionality
- Real-time calculation display
- Backspace/Delete support
- Percentage calculations
- Decimal number support
- Keyboard support for quick calculations

🎨 **Design:**
- Clean and intuitive user interface
- Fully responsive design (works on desktop, tablet, and mobile)
- Modern CSS styling with smooth animations
- Dark theme for comfortable viewing

## Quick Start

### Prerequisites
- Any modern web browser (Chrome, Firefox, Safari, Edge)
- No installation or dependencies required!

### How to Use

1. **Clone the repository:**
   ```bash
   git clone https://github.com/uditprakashyadav-7393/Calculator.git
   cd Calculator
   ```

2. **Open in browser:**
   - Simply open the `index.html` file in your web browser
   - Or use a local server:
     ```bash
     python -m http.server 8000
     ```
   - Then navigate to `http://localhost:8000`

## Usage

### Mouse/Touch
- Click buttons to perform calculations
- Click `C` to clear the display
- Click `=` to get the result

### Keyboard Shortcuts
- `0-9` - Number input
- `+` `-` `*` `/` - Operations
- `=` or `Enter` - Calculate result
- `Backspace` - Delete last digit
- `C` or `Escape` - Clear display
- `.` - Decimal point
